Selected projects

Code and data for each are public on GitHub.

Creep parameters of aluminium from DFT

Quantum ESPRESSO, 141 converged runs: vacancy formation 0.67 eV plus migration 0.59 eV gives Q = 1.26 eV, against 1.28 eV measured.

View on GitHub

Ideal shear strength of Al and Cu

DFT reproduction of Ogata, Li and Yip (Science, 2002): aluminium is stronger than copper in ideal shear (3.19 vs 2.14 GPa).

View on GitHub

Molecular dynamics creep of nickel

Seed-averaged LAMMPS simulations of nanocrystalline nickel, giving a stress exponent typical of grain-boundary creep.

View on GitHub

Machine learning for creep-rupture life

Gradient-boosting model with SHAP analysis showing which composition and test variables control rupture life.

View on GitHub

ML stress prediction for gyroid lattices

Pipeline comparing five regressors on Abaqus compression data (2,525 records): a feature-engineered linear model beat tree ensembles (test MAE 0.14 MPa).

View on GitHub

Thermal-shock testing of ceramic coatings

B.Tech team project: of eight plasma-sprayed alumina coatings tested above 1100 °C, only 20 wt% 3YSZ survived; survival tracked cooling rate.
