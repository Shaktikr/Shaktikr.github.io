Questions

Which file formats do you deliver?

Native files from the CAD program we agree on, plus STEP and IGES so any engineer can open them, PDF drawings, and STL for 3D printing.

Can you work from a photo?

Yes, if the photo includes enough dimensions or a reference object of known size. For tight tolerances, measured dimensions are needed.
