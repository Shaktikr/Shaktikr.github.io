# shaktikr.github.io

Source of [shaktikr.github.io](https://shaktikr.github.io): free engineering calculators (Mohr's circle, beam deflection, FEM demo, Paris-law fatigue, composites, Ashby material selection, XRD peaks, diffusion and creep life, unit converter), concept explainers, and freelance FEM, CAD, MATLAB and computational materials services by Shakti Kumar.

Each tool also has its own page under `tools/`. Contact details, prices and service settings are in the `CONFIG` block near the end of each `index.html`.
